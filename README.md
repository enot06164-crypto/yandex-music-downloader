# Yandex Music Downloader

Приложение для скачивания музыки из Яндекс.Музыки с тёмным GUI, шифрованием токена и встраиванием метаданных.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS-lightgrey.svg)

---

## Возможности

- Поиск треков, альбомов и исполнителей
- Скачивание музыки в качестве до 320 кбит/с
- Автоматическое встраивание метаданных (название, исполнитель, альбом, год, обложка, текст)
- Скачивание по прямой ссылке
- Шифрование токена с привязкой к устройству
- Тёмная тема оформления
- Статистика загрузок

```bash

# Виртуальное окружение
python -m venv venv

# Зависимости
```

## Авторизация

При первом запуске откроется окно авторизации:

1. Нажмите **"Получить токен"** — откроется браузер
2. Войдите в аккаунт Яндекс
3. Скопируйте URL из адресной строки
4. Вставьте ссылку в поле ввода
5. Нажмите **"Войти"**

Приложение автоматически извлечёт токен из ссылки.

## Использование

### Поиск
Введите запрос в поле поиска и нажмите **"Поиск"** или Enter.

### Скачивание
Нажмите кнопку **"Скачать"** на карточке трека. Файл сохранится в `Music/Исполнитель/Трек.mp3`.

### Настройки
Откройте через кнопку **"Настройки"** или меню. Доступные параметры:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Папка для музыки | Путь сохранения | `~/Music` |
| Качество аудио | Лучшее / Высокое / Среднее / Низкое | Лучшее (320 кбит/с) |
| Задержка API | Пауза между запросами (сек) | 0.5 |
| Таймаут | Макс. время ожидания (сек) | 30 |
| Уведомления | Показывать при завершении | Вкл |
| Обложка | Встраивать в файл | Вкл |
| Текст песни | Встраивать в файл | Выкл |

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+F` | Фокус на поиск |
| `Ctrl+S` | Выполнить поиск |
| `Ctrl+L` | Очистить поиск |
| `Esc` | Отменить операцию |
| `F5` | Обновить результаты |

## Безопасность

- Токен шифруется алгоритмом **Fernet + PBKDF2-HMAC-SHA256**
- Привязка к **HWID** устройства — токен не работает на другом ПК
- Токен **не включается** при сборке .exe
- Токен **никогда не записывается** в логи

## Сборка .exe (Windows)

### Шаг 1: Сборка приложения
```bash
build.bat
```
Или вручную:
```bash
pip install pyinstaller
pyinstaller --clean yandexdownloader.spec
```

### Шаг 2: Создание установщика

1. Скачай и установи [Inno Setup](https://jrsoftware.org/isdl.php)
2. Запусти `installer_setup.iss` в Inno Setup Compiler
3. Нажми **Build → Compile**
4. Установщик появится в папке `installer_output/`

### Что включается в сборку
- Все `.py` файлы проекта
- Ресурсы (иконки, изображения) из `resources/`
- Модуль UI из `ui/`
- Все зависимости (PyQt5, cryptography, mutagen и т.д.)

### Что НЕ включается
- `.config/` — личные данные пользователя
- `logs/` — логи
- `__pycache__/` — кэш Python
- Скриншоты и временные файлы

### Установщик
Создаёт профессиональный установщик с:
- Выбором папки установки
- Ярлыком на рабочем столе
- Записью в "Программы и компоненты"
- Корректным удалением через "Установка и удаление программ"

## Решение проблем

| Ошибка | Решение |
|--------|---------|
| Не удалось расшифровать токен | Удалите `.config/config.json` и войдите заново |
| Модуль не найден | `pip install -r requirements.txt` |
| Требуется авторизация | Получите новый токен |
| Трек недоступен | Трек удалён или недоступен в регионе |
