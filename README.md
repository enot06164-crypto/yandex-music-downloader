# Yandex Music Downloader

Приложение для скачивания музыки из Яндекс.Музыки с тёмным GUI, шифрованием токена и встраиванием метаданных.

![Version](https://img.shields.io/badge/Version-0.1.1-orange.svg)

---

## Возможности

- Поиск треков, альбомов и исполнителей
- Постраничная навигация по результатам поиска
- Скачивание музыки в качестве до 320 кбит/с
- Автоматическое встраивание метаданных (название, исполнитель, альбом, год, обложка, текст)
- Скачивание по прямой ссылке на трек/альбом/плейлист
- Шифрование токена (Fernet + PBKDF2-HMAC-SHA256) с привязкой к HWID устройства
- Тёмная тема оформления
- Системные уведомления о завершении загрузки
- Статистика загрузок (всего, объём, сегодня)
- Горячие клавиши
- Skeleton loading анимации
- Экспорт/импорт настроек

---

## Системные требования

- Python 3.8+
- Windows 10+ (для .exe сборки)
- ~50 МБ места на диске

## Установка

### Из исходников


## Авторизация

При первом запуске откроется окно авторизации:

1. Нажмите **«Получить токен»** — откроется браузер
2. Войдите в аккаунт Яндекс
3. Скопируйте URL из адресной строки
4. Вставьте ссылку в поле ввода
5. Нажмите **«Войти»**

Токен шифруется и привязывается к оборудованию (HWID). Повторная авторизация не потребуется.

## Использование

### Поиск

1. Введите запрос в поле поиска
2. Выберите тип поиска: **Треки**, **Исполнитель (все треки)** или **Альбомы**
3. Нажмите **«Поиск»** или `Enter`

Для исполнителей и альбомов доступна постраничная навигация.

### Скачивание

- Нажмите кнопку **«Скачать»** на карточке трека
- Файл сохранится в `Music/Исполнитель/Альбом/Трек.mp3`

### Скачивание по ссылке

1. Нажмите **«Скачать по ссылке»** в меню или.toolbar
2. Вставьте ссылку из Яндекс.Музыки
3. Выберите тип контента (трек / альбом / плейлист)
4. Нажмите **«Скачать»**

### Настройки

Откройте через кнопку **«Настройки»** или меню.

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Папка для музыки | Путь сохранения | `~/Music` |
| Качество аудио | Лучшее (320) / Высокое (192) / Среднее (128) / Низкое (64) | Лучшее |
| Задержка API | Пауза между запросами (сек) | 0.5 |
| Таймаут запросов | Макс. время ожидания (сек) | 30 |
| Уведомления | Показывать системные уведомления | Вкл |
| Обложка | Встраивать в аудиофайл | Вкл |
| Текст песни | Встраивать в аудиофайл (если доступен) | Выкл |
| Формат папки альбома | `{album}` или `{year} - {album}` | `{album}` |

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+F` | Фокус на поле поиска |
| `Ctrl+S` | Выполнить поиск |
| `Ctrl+L` | Очистить поле поиска |
| `Esc` | Отменить текущую операцию |
| `F5` | Повторить поиск |

## Безопасность

- **Шифрование токена**: Fernet-шифрование с ключом, производным от HWID через PBKDF2-HMAC-SHA256
- **Привязка к оборудованию**: Токен не работает на другом устройстве
- **Токен не включается** в сборку .exe
- **Токен никогда не записывается** в логи
- **Соль** хранится отдельно в скрытом файле `.config/.token_salt`

## Сборка .exe (Windows)

### Шаг 1: Сборка приложения

```bash
build.bat
```

Или вручную:

```bash
pip install pyinstaller
pyinstaller --clean yandexdownloader.spec
```

Результат: `dist/YandexMusicDownloader.exe`

### Шаг 2: Создание установщика

1. Скачайте и установите [Inno Setup](https://jrsoftware.org/isdl.php)
2. Откройте `installer_setup.iss` в Inno Setup Compiler
3. Нажмите **Build → Compile**
4. Установщик появится в `installer_output/`

### Что включается в сборку

- Все `.py` файлы проекта
- Ресурсы (иконки, изображения) из `resources/`
- Модуль UI из `ui/`
- Все зависимости (PyQt5, cryptography, mutagen и т.д.)

### Что НЕ включается

- `.config/` — личные данные пользователя
- `logs/` — логи
- `__pycache__/` — кэш Python
- Скриншоты и временные файлы

### Установщик

Создаёт профессиональный установщик с:

- Выбором папки установки
- Ярлыком на рабочем столе
- Записью в «Программы и компоненты»
- Корректным удалением через «Установка и удаление программ»

## Решение проблем

| Ошибка | Решение |
|--------|---------|
| Не удалось расшифровать токен | Удалите `.config/config.json` и войдите заново |
| Модуль не найден | `pip install -r requirements.txt` |
| Требуется авторизация | Получите новый токен через диалог входа |
| Трек недоступен | Трек удалён или недоступен в вашем регионе |
| Приложение не запускается | Проверьте, что установлен Python 3.8+ и все зависимости |
| Нет уведомлений | Проверьте настройки уведомлений в ОС |

## Installation / Установка
